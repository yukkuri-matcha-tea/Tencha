# LINE 26.15.1 対応記録

対象：端末から取得した LINE 26.15.1（versionCode 261510192）の base.apk と arm64 split。Tencha 1.9.5。

## 実APKで確認した変更

26.15.0と比べて14個すべてのDEXが異なるため、単なるバージョンチェック解除は行わず専用対応表を追加した。

| 参照 | 26.15.0 | 26.15.1 |
| --- | --- | --- |
| Compose Composer | j3.r | j3.q |
| Composer実装 / Z()戻り値 | j3.b1 / j3.l3 | j3.c1 / j3.n3 |
| 位置コールバック生成 | z4.y1.a | z4.w1.a |
| LayoutCoordinates | z4.b0 | z4.a0 |
| combined-clickable関連引数 | u1.q1 | u1.r1 |
| ギャラリー時間制限クラス | sp1.u | sp1.x |

位置コールバックは z4.w1.a → u1 → x1 の参照関係と、x1のコールバック引数 z4.a0 を確認。ギャラリーは sp1.x の静的フィールド Y=301000 とコントローラー実装を確認した。アプリ側のレンダラー名 lm2.n / ho1.k / c71.t は維持され、Composer引数が変わっている。

resources.arsc 自体は異なるが、aapt2が出力するresource IDと名前の宣言に差分はなかった。設定入口、チャットID、既読通知、メッセージメニューなどを含む宣言照合は [対応表](line-26.15.1-audit-mappings.json) の50項目で実施する。宣言照合だけでメソッドの全挙動を保証するものではない。

## 通話バイナリ

arm64 split内の次のライブラリは26.15.0と26.15.1でSHA-256が一致した。

- libandromeda.so: `27BED6D41AD1BA14B7F81DC2AD197B4872261E5A3842C3457F3A9E69BB32F8DB`
- libandromeda-renderengine.so: `395301ACEAACBE5D00CA42406930927AF101EDA1CCA54DDB77429B4677DF0921`

既存の録音コールバック位置を維持し、26.15.1を明示的に許可した。インストール時の命令列検査と、音声機能使用時のみ遅延初期化する安全策は維持する。未確認の将来版は許可しない。Java側のパーティーメニュー、TTS受信処理、通話画面メソッドの宣言も現APKで確認した。

## 変更範囲と検証

専用対応表、通話版判定、バージョン番号と回帰テストを変更した。通話画面を離れた時の音声停止、既存設定、その他のUI・ライフサイクル処理は変更していない。

2026-10-09に自動テスト37件（失敗0）、APK宣言50項目の照合、Android Lint、APKビルドを確認した。接続端末へ1.9.5を更新インストールし、LINEを完全終了して再起動した。

Tencha本体の「LINEに接続済み / Vector経由で動作中（root）」、LINE 26.15.1 / Tencha 1.9.5の表示をスクリーンショットで確認。LINEの設定にTenchaセクションと「モジュール設定」が表示され、タップで設定画面が開くことをUI階層で確認した。設定は変更していない。

相手への音声到達、TTS、全機能の実機操作は未検証であり、上記の起動・設定入口確認と区別する。
