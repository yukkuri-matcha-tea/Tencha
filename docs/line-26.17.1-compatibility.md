# LINE 26.17.1 の対応と確認範囲

端末から取得した LINE 26.17.1（261710173）の base APK と arm64・xxhdpi split を対象にした。バージョン別に確認した参照を登録し、未解析の 26.17.0 は従来どおり対象外。

| 領域 | 確認した参照と変更 |
| --- | --- |
| LINE設定 | `ji5.b` の一覧が `ak8.f$b` をバインドし、`id5.a` が `jd5.v` と `jd5.a0` を包む。設定リスト・個人情報見出し・行の各リソースIDを照合。LINE本来の行描画が例外を投げた場合に同じ処理を呼び直す経路も除去。 |
| ホーム・トーク一覧 | `di8.f.a()` が実際のタブ一覧を構築。設定長押しのCompose参照、トーク一覧の `z42.a`、Agent i の表示判定と描画を更新。既読回避はトーク一覧の「＋」で使われる `d71.t.c` の行に追加する。 |
| 取消・既読・チャット | 取消は `ls8.z0`、既読は `ls8.x1`、リアクションは `ls8.h2`。`jr1.y.I0` が受け取る `ve1.h` からメッセージ情報を読む。チャットID、検索、選択、アナウンスの参照も更新。 |
| 長押し・編集履歴 | 長押しのテキストを対応するポップアップの表示処理内だけで保持。26.17.1の検索項目にはAPKに残っている `navi_top_search` を使用できる。編集履歴は `xm1.d1` のラベル・アイコン・動作を解決してから項目を追加する。 |
| 通話 | 音声ライブラリ `libandromeda.so` の SHA-256 は前版と同一。JNIのミュート・セッション解放、通話設定、TTS受信・グループ識別、音源の参照を更新。独立ミュートの解除を実際のセッションIDと照合する。起動時に失敗した通話設定の LiveData は、具象クラスの生成と最新版の値設定メソッドで修正。 |
| プロフィール・動画・フォント | オブジェクト閲覧で編集機構を使う前に `C7(nm6.h)` の保存抑止を登録する。表示・選択・終了の参照を更新。動画の時間チェックだけを緩和し、容量など他のチェックを残す。カメラの消音対象は SoundPool ごとに管理し、フォントの読込先を更新。 |
| 通知・テーマ | Firebase、LEGY、ダークテーマの参照を更新。Firebaseトークンの値はログに出さない。 |

`Audit-LineHookTargets.py` で77個のHook・補助ファイルを走査し、設定から参照する135クラスと直接追える16個のメソッドを照合した。別途、`Verify-LineApk.py` で実APKの212,571クラスを索引化し、確認対象の212宣言すべてで引数・戻り値・フィールド型の一致を確認した。

修正版を上書きインストールしてLINEを再起動した。起動後のログで通話設定と取消マークのフック登録を確認し、確認中にクラッシュ・参照先未解決は出なかった。LINE設定のTencha行、モジュール設定の6分類、TTSの検索結果と無関係な項目の非表示、チャット内で表示された7件の秒表示を実機で確認した。単体テスト92件成功、Lintエラー0。

追加の実機確認では、「＋」から既読回避をONにして元のOFFへ戻し、長押しメニューに検索・翻訳が表示されることを確認した。チャットからトーク一覧への復帰、他人のプロフィール閲覧モードへの再入場とオブジェクト一覧、TTSとサウンドボードの設定画面も確認した。サウンドボードではWAVを取り込んで登録件数が99件から100件に増えること、一覧を末尾までスクロールしてテスト音声を削除すると99件に戻ることを確認した。端末のログでVOICEVOXの異常終了が見つかったため、TTSエンジンから結果が返らない場合に、次の読み上げへ進めるようにした。

新規の取消・既読通知、対向端末への通話音声、検索・翻訳の結果、プロフィールオブジェクトの全操作、通知配送、非root端末は実機での一連の確認が残っている。

## 追加の静的解析

- 既読処理 `ls8.x1.b` の最終既読IDは、トークの読み取り位置を表す。初回はその位置以下で最も新しい自分のメッセージを1件探す。以降は前回から今回までを対象にする。履歴への記録と削除は同じロックで直列化し、メッセージDBを読めなかったときは読み取り位置を進めない。
- `n41.c.a(Intent)` が読む `chatHistoryRequest` を、メンバー別検索、既読履歴、リアクション通知のトーク識別で共通に使う。リアクション通知は通知IDごとの遷移を保持する。
- プロフィール保存に26.17.1の `album_toolbar_icon_download_overlay` を使えるようにした。配置画像は `yv6.q1.j` から `yv6.l1.b` を呼び、LINE標準の画像ローダーへ渡す経路を照合した。

既読履歴のSQLをテスト用のSQLiteデータ4ケースで確認した。この追加修正は静的解析・ビルドまで。

```powershell
python scripts/Audit-LineHookTargets.py ../line-26.17.1-apk/base.apk Version26171
python scripts/Verify-LineApk.py ../line-26.17.1-apk/base.apk docs/line-26.17.1-audit-mappings.json
./gradlew.bat spotlessCheck testDebugUnitTest lintDebug assembleDebug
```
