- サウンドボード管理画面が登録99件を表示。ScrollView、スクロール操作、固定された「音声を追加」「閉じる」ボタンの存在を確認。再生・追加・削除・並び替え保存は行っていない。

- これらの操作中、新しいTencha登録エラー・FATAL EXCEPTIONは確認しなかった。

## 発見した不具合と修正

設定の絞り込みが直下の行だけを見ており、開発者項目を格納する入れ子のLinearLayoutを処理していなかった。そのため有効な開発者グループが検索中も全表示され、検索を消す経路ではOFFのグループまでVISIBLEに戻す可能性があった。

- 開発者グループを明示的に識別し、子の行とセクション見出しも再帰的に絞り込む。
- 開発者モードOFFのグループは検索/クリアのどちらでも非表示を維持する。
- 開発者モード切り替え時には現在の検索条件で設定一覧を再構築する。
- 大文字小文字の正規化はLocale.ROOTへ統一。
- 無関係なグループの非表示、検索解除時のOFF維持、トルコ語ロケールの回帰テスト3件を追加。
