# サウンドボードの並び替え

LINE内のTencha設定 → 通話 → サウンドボード音声で、各音声の右側の「≡」を押したまま上下にドラッグする。画面端で自動スクロールし、指を離したときに保存する。画面外へのドロップ・キャンセルでは保存せず元の順番へ戻る。名前のタップは削除確認、下のボタンは音声追加と閉じる。アクセシビリティのクリック操作では移動先選択も利用できる。

Android標準のDrag/DropとScrollViewを使い、LINE内の難読化されたRecyclerViewのAdapterには依存しない。アニメーション追加前のスイッチは変更しない。音声は再生せず、インデックスだけを変更し、WAVファイル・ID・名前を維持する。

ドラッグ中の順番を、保存直前に取得した最新のクリップ一覧へIDでマージする。重複した指定と削除済みIDは無視し、途中で追加された音声は保持する。追加・削除・並び替えのインデックス更新を同じロックで直列化する。保存失敗時は以前の順序を復元する。通話側は同じ保存順をロードするため、パーティー画面を開き直した際に反映される。

ユニットテスト50件、Spotless、Android Lint（エラー0）、APKビルドを確認。接続端末でドラッグによる隣接行の入れ替えと、ドロップ後のインデックス再読み込みを確認し、その後に元の順番へ戻した。音声再生・通話・メッセージ送信は行っていない。長い一覧の自動スクロール・キャンセル・通話パーティー画面への反映は実装経路の確認のみで、実機操作は未検証。
